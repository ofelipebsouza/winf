## 🛠️ Key Modules

### 🧠 WINF BRAIN™ (AI Assistant)
An executive assistant powered by Google Gemini. It performs complex data analysis, summarizes operations, and provides strategic recommendations in natural language.

### 🧬 Molecular Twin™ (Gêmeo Molecular)
The pinnacle of WINF™ technology. A digital twin simulator that creates a molecular model of the client's glass, predicting heat reduction, UV rejection, and energy gains with scientific accuracy.

### 📐 WINF Precision™
A mathematical cutting optimizer that reduces material waste by calculating the best layout for film rolls in real-time.

### 📄 Elite Quotes (Orçamentos Elite)
High-standard PDF proposal generator. Delivers impeccable documents with automated tax, ROI, and margin calculations in seconds.

### 🏁 Mission Control & The Board
Centralized dashboards for administrators and CEOs to monitor the entire network of licensees, lead flows, and market saturation.

## 🚀 Tech Stack

- **Frontend:** React 19 + Vite (SPA)
- **Styling:** Tailwind CSS 4 (Custom Design System)
- **State Management:** Zustand
- **Animations:** Motion (Framer Motion) for fluid micro-interactions
- **Backend/DB:** Firebase (Firestore, Auth, Cloud Functions)
- **AI Engine:** Google Gemini Pro & Anthropic Claude
- **3D Visualization:** Three.js / React Three Fiber
- **Maps:** Leaflet & React Leaflet
- **Communication:** MQTT & Socket.io for real-time synchronization
- **Reports:** @react-pdf/renderer & JsPDF

## ⚙️ Getting Started

### Prerequisites
- Node.js (Latest LTS recommended)
- npm or yarn

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/eco-sistema-winf.git
   cd eco-sistema-winf
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Configure Environment Variables:**
   Create a `.env` file in the root directory and add your API keys:
   ```env
   GEMINI_API_KEY=your_key_here
   ```

4. **Start the development server:**
   ```bash
   npm run dev
   ```

5. **Build for production:**
   ```bash
   npm run build
   ```
